## 기존 기능 개선 후보

- 저장 직후 "휴대폰으로 테스트 스캔하세요" 안내.
- 금액 입력에 쉼표 소수점(`12,50`) 허용.
- 랜딩 하단에 "관련 생성기 3개 + 사용 사례 2개" 카드(현재 푸터 텍스트 링크만). AdSense 안내도 글 끝 관련 링크를 권장.
- 일본어 제목에 "QRコード 作成 無料", 한국어 제목에 "QR코드 만들기" 반영.

## 하지 않을 것

1. **동적 QR·리다이렉트 서버** — 피싱 QR 악용 신고·삭제 대응·영구 가동 책임을 떠안는다. 1인 운영 불가. (ADR-001)
2. **파일·이미지·PDF 호스팅, 링크 모음 페이지** — 저작권·악성 파일·AdSense 정책 위험 + 저장 비용.
3. **회원가입·계정·스캔 통계** — 동적 QR 전제. 개인정보 부담.
4. **앱 다운로드 기기 분기 QR** — 리다이렉트 필요.
5. **QRIS·Swiss QR-bill** — 발급 기관 등록, 엄격한 규격. 오류 시 결제 실패 책임.
6. **AI 아트 QR** — GPU 비용, 스캔 실패율.
7. **공개 API** — 남용·대역폭.
8. **광고 슬롯 6개 초과·자동 광고** — 실수 클릭 위험.
